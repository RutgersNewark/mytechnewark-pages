Microsoft Education LTI Replaces Legacy Office 365 Integration

Rutgers Canvas has launched the Microsoft Education LTI, Microsoft's latest integration for Canvas. The new integration provides access to OneDrive files, Microsoft 365 documents, and collaboration tools directly within Canvas.

Microsoft Education LTI allows instructors and students to:

  • Embed Microsoft files directly into Canvas content
  • Create and share files from OneDrive within Canvas
  • Use Microsoft documents as assignment templates
  • Maintain file ownership and storage within Microsoft 365 accounts

The new integration replaces the legacy Microsoft Office 365 LTI 1.1. New content can no longer be created using the legacy integration.

What Faculty Need to Know

There is no automatic migration from legacy Office 365 LTI links to Microsoft Education LTI. Faculty should review Canvas courses containing Microsoft content created with the older integration and recreate any content that needs to remain available using Microsoft Education LTI.

This may include:

  • Microsoft files embedded in Canvas Pages, Assignments, Syllabi, Quizzes, Announcements, and Discussions
  • Microsoft files used as assignment templates
  • Canvas Collaborations created using the legacy Office 365 integration
  • Microsoft content copied forward from previous Canvas courses

Files stored in OneDrive are not deleted and remain available through OneDrive and Microsoft 365.

Export Your Legacy Portfolio Content Before December 31

Canvas users who have content in ePortfolios (Legacy) or Folio (Legacy) should preserve any content they want to keep before December 31, 2026.

Rutgers has transitioned to Canvas Portfolio, a new integrated portfolio platform that supports both student-created showcase portfolios and instructor-guided evaluation portfolios.

If You Use ePortfolios (Legacy)

Download the contents of your portfolio as a ZIP file and save it to a secure location.

If You Use Folio (Legacy)

Download and save any portfolio artifacts, files, and evidence you want to retain.

Folio content is not automatically transferred to Canvas Portfolio. Content that users want in the new system must be added manually.

Canvas Portfolio Updates

Several enhancements to Canvas Portfolio become available beginning September 19, 2026, making it easier for instructors and students to build, maintain, and share portfolios.

Import Canvas Assignments

Instructors can import multiple Canvas assignments directly into a portfolio and use them as requirements.

Imported assignments create editable requirement cards and include a link back to the original Canvas assignment. Changes made in Portfolio do not sync back to the original Canvas assignment.

Capture Assignment Snapshots

When students add an assignment submission as portfolio evidence, Canvas captures a snapshot of the submission at that point in time.

Students can add the same assignment multiple times to demonstrate progress across different versions of their work.

Comments on Shared Portfolio Content

Rutgers Canvas users can sign in with their existing Canvas account to comment on shared portfolio evidence.

Portfolio owners retain control and can disable commenting on their shared content.

Embed Interactive Content

Users can embed external content such as YouTube videos, Google Slides, Miro boards, and other HTML-based interactive content directly into portfolios and evidence items.

Update Published Evaluation Portfolios

Instructors can now make certain additions to an evaluation portfolio after it has been published, including adding courses, requirements, and sections.

Existing requirements remain protected from substantive changes, helping preserve student progress while allowing portfolios to evolve across semesters or programs.
