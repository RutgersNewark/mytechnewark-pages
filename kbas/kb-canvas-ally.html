Using Ally to Improve Course Accessibility

Ally is built into your Canvas course and identifies accessibility issues in your files, provides step-by-step remediation guidance, and automatically generates alternative formats for students — so you can make meaningful improvements without starting from scratch.

Category:  Accessibility & Inclusion
Last reviewed:  May 2026
Reviewed by:  ATS, Rutgers–Newark

What Ally Does

Ally reviews every file and piece of content in your Canvas course and displays a colored accessibility score next to each item. Clicking that score opens a guided feedback panel that explains what the issue is, why it matters, and exactly how to fix it. Ally also automatically generates alternative formats — audio, HTML, ePub, tagged PDF, and electronic braille — that students can download from any course file at any time.

Ally works best as an ongoing course improvement tool, not a one-time checklist. Small, consistent improvements each semester add up to a significantly more accessible course over time.

🔧
Software & Integrations
Ally is active in all Rutgers Canvas courses — no installation or setup required. Accessibility score indicators appear automatically next to files and content in your course. Students can already download alternative formats from any course file; you do not need to enable this separately. The full report is available from the Ally Course Accessibility Report link in your Canvas course navigation.

Understanding Accessibility Scores

Ally displays a colored gauge next to each file and piece of course content. Here's what each level means and how to prioritize your work:

Low Score (Red) — Prioritize First Significant accessibility barriers are present. Students using screen readers or assistive technology may be unable to access this content at all. Address these items before anything else.
Medium Score (Orange / Yellow) — Address Next The content is partially accessible but still creates barriers for some students. These items are worth improving once your red-scored materials are resolved.
High Score (Light / Dark Green) — In Good Shape The content follows good accessibility practices. No immediate action needed — maintain this standard when updating or replacing files.

How to Use Ally in Your Course

  1. Review accessibility indicators in your course — Look for the Ally score gauge next to files and content items. Start with the materials that affect the most students: syllabus, major assignment instructions, weekly overview pages, and core readings.
  2. Open the feedback panel — Click any accessibility score indicator to open the Ally Feedback panel. It explains what the issue is, why it matters to students, and gives step-by-step instructions for fixing it. You do not need to know anything about accessibility standards to follow the guidance.
  3. Fix quick wins first — You do not need to redesign your entire course. Start with small, high-impact changes that take only a few minutes each.
  4. Open the Course Accessibility Report — Click Ally in your Canvas course navigation to view the full report. It shows your overall course accessibility score, lists low-scoring content across the entire course, and lets you filter by file type or score range. This is the best starting point for improving an older course with many files.
  5. Update the source file, not just the upload — When a Word document or PowerPoint has accessibility issues, fix the original file and re-upload it to Canvas rather than trying to edit only the uploaded version. This improves the Ally score, student usability, and the quality of the automatically generated alternative formats.
  6. Review Ally indicators whenever you add new content — Make it a habit to check scores as you build or update your course each semester. A few minutes of review per new file prevents accessibility debt from accumulating.

Common Issues Ally Identifies

Issue Why it matters Quick fix
Missing heading structure Screen readers navigate documents by headings — without them, the document is a single undifferentiated block of text Apply real Heading styles (H1, H2, H3) in Word or Google Docs, not bold text
Images without alt text Students using screen readers cannot access any information conveyed by images without a text description Add a meaningful alt text description to each image; mark decorative images as decorative
Poor color contrast Low contrast text is difficult or impossible to read for students with low vision or color blindness Increase contrast between text and background colors; avoid light gray text on white
Non-descriptive links "Click here" or "Read more" give screen reader users no context about where a link goes Replace with descriptive text: "Download the Course Syllabus" or "View Week 3 Reading"
Improper table structure Tables without header rows are disorienting for screen readers — data cells have no column or row labels Add a header row to every table and mark it as a header row in the document formatting
Scanned (image-only) PDFs A scanned PDF is an image — screen readers cannot read it, and Ally cannot generate useful alternative formats from it Replace with the original accessible document, or run OCR on the scan to create a text layer

Recommended Order of Improvement

Start Here
High-use, high-impact materials Syllabus, major assignment instructions, weekly overview pages, and core required readings. These affect every student in the course and should be accessible from day one.
Next
Module content and handouts Lecture slides, in-class handouts, supplemental readings, and older course files that students access regularly throughout the semester.
Ongoing
New content as you add it Check Ally scores whenever you upload a new file or create a new Canvas page. Catching issues early is faster than fixing a backlog at the end of the semester.

Rutgers–Newark Workflow
At Rutgers–Newark, ATS recommends opening the Course Accessibility Report at the start of each semester — especially for courses you've taught before — and addressing your top three to five lowest-scoring items before the first day of class. This takes less time than it sounds: most high-impact fixes (adding headings, writing alt text, replacing a scanned PDF) take under five minutes each in the original source document. ATS can review your course with you during a pre-semester consultation.

Alternative Formats for Students

Ally automatically generates alternative formats for every file in your course. Students can download these directly from any course file without requesting them from you. Available formats include audio (MP3), HTML, ePub, tagged PDF, and electronic braille. Translated formats may also be available depending on the file.

These formats benefit students using assistive technology, students reading on mobile devices, students who prefer audio while commuting or exercising, and students with varying learning preferences. Remind students in your syllabus or course overview that these formats are available — many students don't know to look for them.

💡 What Ally Does Not Replace
Ally is a powerful diagnostic and generation tool, but it does not automatically fix your documents or replace good authoring practices. Real headings, descriptive links, captioned videos, and logical document structure still need to come from you. Some issues — particularly complex PDFs or scanned documents — may require additional remediation support beyond what Ally's feedback panel covers.

Do's and Don'ts

✓ Do
  • Improve accessibility incrementally — a few fixes per semester add up
  • Start with high-use materials: syllabus, assignments, core readings
  • Update the original source file, not just the Canvas upload
  • Use the Course Accessibility Report to find patterns across the whole course
  • Caption media and use descriptive headings and links
  • Remind students that alternative formats are available
  • Check Ally scores whenever you add new content
✕ Don't
  • Treat Ally as a one-time compliance checklist
  • Ignore red-scored items on core course materials
  • Upload image-only scanned PDFs without an accessible source
  • Use bold text as a substitute for real document headings
  • Assume Ally automatically fixes the issues it identifies
  • Wait until the end of the semester to review accessibility
