Using Library Reading Lists (Leganto) in Canvas

How To Manage Course Materials Leganto Reading Lists Course Reserves Canvas Library OER

Library Reading Lists, powered by Leganto, is a Rutgers University Libraries tool integrated directly into Canvas. It lets you build, organize, and share course reading lists drawn from Rutgers library collections and other sources — all within your Canvas course.

Overview

Library Reading Lists (powered by Leganto) replaces the traditional course reserves process with a streamlined, fully integrated workflow inside Canvas. Instead of directing students to search library websites and databases separately, you build one organized reading list that lives in your Canvas course — with direct links to every item.

The service and Canvas integration are provided and maintained by Rutgers University Libraries, not by campus IT. For content questions, reserve requests, and library support, contact the Libraries directly (see Getting Help below).

About This Tool Library Reading Lists is an enterprise tool licensed and supported by Rutgers University Libraries for all Rutgers instructors teaching Canvas courses. The tool appears as Library Reading Lists in Canvas course navigation. Technical configuration is handled by the Libraries — instructors do not need to install or configure anything beyond enabling it in their course navigation.

Access and Prerequisites

To use Library Reading Lists you need:

  • An active Rutgers NetID
  • An active Canvas course (the course does not need to be published to set up a reading list, but should be published before students need to access it)
  • Instructor role in the Canvas course
  • Library Reading Lists enabled in your course navigation (see next section)
Provided by Rutgers University Libraries The Library Reading Lists enterprise license and Canvas integration are provided by Rutgers University Libraries. For access issues, content questions, and reserve requests, contact the Libraries — not campus IT or ATS. For Rutgers–Newark faculty, the Newark Libraries teaching support page is libraries.rutgers.edu/newark/teaching-research-help.

Enable Library Reading Lists in Canvas

The tool must be enabled in your course navigation before students can see it. This is a one-time setup per course.

  1. 1
    Open your Canvas course — Log in at rutgers.instructure.com and navigate to the course.
  2. 2
    Go to Settings — Select Settings in the course navigation menu.
  3. 3
    Open the Navigation tab — Select the Navigation tab at the top of the Settings page.
  4. 4
    Enable Library Reading Lists — Find Library Reading Lists in the hidden items list and drag it into the active navigation section.
  5. 5
    Select Save — Scroll down and select the Save button.
  6. 6
    Launch the tool — Select Library Reading Lists in your course navigation. Leganto opens and automatically associates with your Canvas course.
Visibility Tip Enabling the tool in course navigation makes it visible to you immediately, but students only see it once you publish your reading list. Keep the list in Draft while you build it, then publish when it is ready for students.

Create or Connect a Reading List

  1. 1
    Launch Library Reading Lists from your Canvas course — Leganto opens in your course context and detects your course automatically.
  2. 2
    Create a new list or connect to an existing one — To start fresh, select Create a New List. To reuse a list from a previous term, select Connect to an Existing List and search for it by name or course code.
  3. 3
    Give the list a clear title — Include the course name, term, and section if relevant (e.g. SOC 101 — Spring 2026 — Section 01). Students see this title in Canvas.
  4. 4
    Confirm the course and term association — Verify the list is linked to the correct Canvas course and semester. Incorrect associations can cause students from wrong sections to see the list.
  5. 5
    Save your list — The list is created in Draft status. It is not visible to students until you publish it.
Rollover Tip When reusing a list from a prior term, connect to the existing list and update it rather than rebuilding from scratch. Update item availability, replace anything that is no longer accessible, and adjust due dates before publishing. This saves significant time at the start of each semester.

Organize Your List

  1. 1
    Add sections to structure the list — Select Add Section and name it by week, topic, or assignment (e.g. Week 1: Introduction, Module 3: Research Methods). Sections create clear visual groupings for students.
  2. 2
    Add due dates and notes to sections — For each section, optionally add a due date and instructor notes or instructions. Notes appear to students alongside the readings.
  3. 3
    Mark readings as Required or Optional — Use the required/optional label on individual items to signal to students which readings are essential. This is especially useful in courses with extensive reading lists.

Add Materials to Your List

Leganto supports a wide range of material types:

Books & Ebooks Journal Articles Streaming Media Book Chapters Websites & Web Resources YouTube & Videos OER Materials Uploaded Files Manual Citations
  1. 1
    Search Rutgers Libraries — Use the built-in search (powered by QuickSearch) to find books, articles, ebooks, and streaming media in Rutgers library collections. Leganto shows availability status alongside each result.
  2. 2
    Add open web resources — Select Add Web Resource and paste a URL to add websites, YouTube videos, OER materials, and other freely available content.
  3. 3
    Upload files — Upload instructor-owned documents or materials you have cleared for sharing. Only upload files you own or have permission to distribute — see the copyright note below.
  4. 4
    Enter a manual citation — If an item cannot be found via search, select Add Citation Manually and enter the details. This is useful for materials not yet in the library catalog or items from external sources.
  5. 5
    Drag and drop to reorder — Once items are added, drag them to reorder within sections or move them between sections.
Copyright and Course Materials Instructors are responsible for complying with copyright guidelines. When uploading files, only include materials you own, materials covered by Rutgers library licenses, or items within fair use guidelines. For questions about whether a specific item can be shared, contact the Rutgers Libraries copyright queue at copyright@rutgers.libanswers.com before uploading.

Request Course Reserves and Scans

If students need access to a physical item, a new acquisition, or a digitized portion of a print resource, submit a request to Rutgers University Libraries using the reserve request form.

  • Place physical items on reserve — request a library-owned item to be placed on short-term loan at your campus library
  • Request a new acquisition — ask the library to purchase a title not currently in the collection
  • Request a chapter scan — ask the library to digitize a portion of a print item within copyright guidelines
Lead Times — Plan Ahead Submit reserve requests as early as possible — preferably several weeks before the semester begins. Requests submitted during the first weeks of class may be delayed due to high processing volume. New acquisitions may take an additional 2–6 weeks to order, receive, and process before becoming available to students. The reserve request form accepts up to 40 items per course. For larger requests or multiple courses, submit separate forms.

What Students See

Once you publish your reading list, students access it by selecting Library Reading Lists in the Canvas course navigation — the same link you use to manage it. Students see:

  • Full citation details for each item including author, title, publisher, and year
  • Direct links to access ebooks, articles, and streaming media through Rutgers library systems
  • Availability status — whether an item is available online, on reserve, or requires a library visit
  • Required or optional labels and any instructor notes you have added
  • Uploaded files or linked web resources you have added directly
Ebook Access Note Some ebooks licensed by Rutgers Libraries have limits on the number of simultaneous users. If students report they cannot access an ebook, the license may be at capacity. Contact the Libraries to request an additional license or identify an alternative format. Directing students to the physical copy via standard library loan is also an option.

Monitor and Maintain Your List

  • Check item statuses during the term — Leganto shows availability status for each item. Check periodically to catch items that have become unavailable or need library review.
  • Update or replace unavailable items — If an item goes unavailable or a license limit is hit, update the list promptly. Post a Canvas announcement to notify students of any changes.
  • Review usage analytics — Leganto tracks which items students view and access. Review this data mid-semester to identify readings students are skipping — it often surfaces unclear instructions or broken links.
  • Reuse and update at the end of term — When the course ends, your list is saved in Leganto. At the start of the next term, connect to the existing list, update any changed items, confirm availability, and republish.

Troubleshooting

ProblemWhat to Do
Library Reading Lists link not visible in course navigation Go to Course Settings → Navigation tab and enable Library Reading Lists from the hidden items list. If it does not appear in the list at all, contact Rutgers University Libraries — the integration may need to be enabled at the account level.
Reading list not associated with the correct course or term In Leganto, check the course and term association in the list settings. Disconnect and reconnect to the correct Canvas course if needed. Contact the Libraries if you cannot resolve the association.
Items showing as unavailable or needing library review Items flagged for library review are being processed — allow processing time, especially at the start of a semester. For items that remain unavailable, submit a reserve request or contact the Libraries to identify an alternative.
Students cannot access specific readings Ask the student to confirm they are logged in with their Rutgers NetID. Check the item's availability status in Leganto. For ebook access limits, contact the Libraries to request an additional license. For broken links, update the item in your reading list.
Students encounter simultaneous user limits on ebooks Contact Rutgers University Libraries to request an additional license for the title. In the interim, direct students to the physical copy or an alternative format. Post a Canvas announcement so students know what to expect.
Reserve request has not been processed Check the lead time — new acquisitions can take 2–6 weeks. For status updates on submitted requests, email acquisitions@rutgers.libanswers.com. Submit requests as early as possible to avoid delays at the start of term.
